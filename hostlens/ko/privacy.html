HostLens 개인정보처리방침

시행일: 2026년 10월 12일

제공자: Creatrix(크리에이트릭스) · 문의: creatrix.studio26@gmail.com

요약

  • 계정, 광고, 추적이 없고 어떤 데이터도 판매하지 않아요.
  • 네트워크 정보는 iPhone 밖으로 나가지 않아요. IP 주소, 기기 이름, 스캔 결과, DNS 결과, 기록은 모두 기기 안에서만 처리하고 저장해요.
  • 앱을 개선하기 위해 익명 사용 이벤트(Google Analytics for Firebase)와 오류 보고(Sentry)를 수집해요. 둘 다 설정 → 개인정보에서 끌 수 있어요. 유럽경제지역(EEA), 영국, 스위스 사용자에게는 사용 분석을 켜지 않아요.

기기에만 남는 데이터

HostLens는 기기의 네트워크 설정(로컬 IP 주소, 서브넷, 공유기 주소, DNS 서버)을 읽고, 연결 상태와 응답 시간을 재기 위해 로컬 네트워크와 공개 테스트 호스트(예: apple.com, 1.1.1.1)에 네트워크 요청을 보내요. 네트워크에서 찾은 기기를 포함한 결과는 iPhone의 앱 저장 공간에만 보관되고, 직접 지우거나 앱을 삭제하면 사라져요. 저희는 이 데이터를 받지 않아요.

사용 분석 (Google Analytics for Firebase)

사용 분석이 켜져 있으면 '점검 완료', '스캔 완료'(대략적인 기기 수 구간), '결제 화면 표시', '구매 완료' 같은 익명 이벤트를 보내요. Firebase는 앱 인스턴스 식별자, 기기 모델, OS 버전, 앱 버전, 언어, 접속 정보로 추정한 대략적인 국가도 처리해요. 이벤트에는 IP 주소, 기기 이름, 호스트 이름, DNS 결과, 스캔 결과가 절대 포함되지 않아요. 광고 기능은 꺼 두었고 광고 식별자(IDFA)를 사용하지 않아요. 보관 기간은 2개월이에요. 제공자: Google LLC(미국).

오류 보고 (Sentry)

오류 보고가 켜져 있으면 앱이 멈추거나 비정상 종료될 때 기술 정보(스택 트레이스, 기기 모델, OS와 앱 버전)를 보내요. 전송 전에 앱이 보고서에서 IP 주소와 호스트 이름을 지우고, 서비스도 IP 주소를 저장하지 않도록 설정해 두었어요. 보관 기간은 최대 90일이에요. 제공자: Functional Software, Inc. d/b/a Sentry(미국).

결제

결제는 Apple이 처리해요. 저희는 내 기기에서 HostLens Pro를 활성화하는 데 필요한 정보만 받고, 결제 정보는 볼 수 없어요.

국외 이전 안내

익명 사용 이벤트와 오류 보고는 앱 측정과 개선 목적으로만 위 제공자에게 전송되어 미국에서 위에 적힌 기간 동안 보관돼요. 설정 → 개인정보에서 '사용 분석'과 '오류 보고'를 끄면 이전을 거부할 수 있고, 꺼도 앱의 모든 기능을 그대로 쓸 수 있어요.

아동

HostLens는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 알면서 수집하지 않아요.

선택과 권리

설정 → 개인정보에서 언제든 사용 분석과 오류 보고를 끌 수 있어요. 저희가 받는 데이터는 개인과 연결되지 않아서 보통 특정인의 데이터로 식별할 수 없어요. 요청이나 문의가 있으면 creatrix.studio26@gmail.com으로 연락해 주세요. 최대한 도와드릴게요.

변경

앱의 데이터 처리 방식이 바뀌면 이 방침을 고치고 위의 시행일을 새로 표시할게요.
