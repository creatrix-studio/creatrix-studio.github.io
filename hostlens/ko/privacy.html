휴대폰에만 남는 데이터

HostLens는 휴대폰의 네트워크 설정(로컬 IP 주소, 서브넷, 공유기 주소, DNS 서버)을 읽고, 연결 상태와 응답 시간을 재기 위해 로컬 네트워크와 공개 테스트 호스트(예: apple.com, 1.1.1.1)에 네트워크 요청을 보내요. 네트워크에서 찾은 기기를 포함한 결과는 휴대폰의 앱 저장 공간에만 보관되고, 직접 지우거나 앱을 삭제하면 사라져요. 저희는 이 데이터를 받지 않아요.

사용 분석 (Google Analytics for Firebase)

‘점검 완료’, ‘구매 화면 표시’, ‘구매 완료’ 같은 익명 제품 사용 이벤트를 보내요. 또한 기기 지역, 앱 언어, 구매 상태, 알림 허용 여부, 앱을 처음 연 주를 정해진 값으로만 보내요. Firebase는 앱 인스턴스 식별자, 기기 모델, OS 버전, 앱 버전, 언어와 연결에서 추정한 국가도 처리해요. 이벤트에는 IP 주소, 호스트 이름, 기기 이름, UPnP·SNMP 정보, DNS 결과, 주소 범위나 스캔 데이터를 넣지 않아요. 광고 기능은 꺼 두었고 광고 식별자(IDFA)는 쓰지 않아요. 보관 기간은 2개월이에요. 제공 업체: Google LLC(미국). 이 가운데 스캔 실패와 그 이유, 구매 같은 일부 이벤트는 정확하게 집계하려고 저희 서버로도 보내요. 서버는 이벤트 이름과 정해진 값, 발생 시각, 앱·OS 버전, 플랫폼만 받아요. IP 주소나 사용자·기기 식별자는 저장하지 않고, IP 주소는 반복 전송을 막는 데에만 메모리에서 써요. 이벤트는 1년 뒤에 삭제해요. 서버는 Oracle Cloud Infrastructure에서 운영하고, 데이터는 미국의 Supabase, Inc.가 보관해요. EEA·영국·스위스에서의 법적 근거: 이용자의 동의.

오류·성능 보고 (Sentry)

충돌·멈춤·성능 보고를 보내요. 스택 추적, 기기 모델, OS·앱 버전, 세션이 정상적으로 끝났는지, 앱 시작과 화면 표시에 걸린 시간, 최근에 연 화면과 앱 동작 기록이 담겨요. 저희 서버로 보낸 요청은 경로, 상태, 걸린 시간만 기록하고, 내 네트워크나 테스트 호스트로 보낸 요청은 기록하지 않아요. 보내기 전에 자유롭게 입력된 내용과 네트워크 데이터를 지워요. IP 주소, 호스트 이름, 기기 이름, UPnP·SNMP 정보, DNS 결과, 주소 범위와 스캔 데이터도 모두 지워요. 서비스에서도 IP 주소를 저장하지 않도록 설정했어요. 보고서는 최대 90일 보관해요. 제공 업체: Functional Software, Inc. d/b/a Sentry(미국). EEA·영국·스위스에서의 법적 근거: 이용자의 동의.

속도 측정과 공유기 페이지

속도 측정은 Netflix가 운영하는 FAST.com을 앱 안 브라우저로 열어요. 측정은 FAST.com의 개인정보처리방침에 따라 이루어지고, HostLens는 결과를 받지 않아요. '공유기 설정 열기'는 로컬 네트워크에 있는 내 공유기의 웹 페이지를 열어요.

의견 보내기

설정에서 의견을 보내면 메시지, 선택한 유형, 앱·OS 버전, 앱 언어가 전송돼요. 계정, 이메일 주소, 기기 ID, 네트워크나 기기 정보는 전송되지 않고, 사용자를 구분하는 ID도 만들지 않아요. 데이터는 '보내기'를 누를 때 암호화된 연결로 전송되고, 저희 서버(Oracle Cloud Infrastructure에서 운영)에서 처리되어 미국의 Supabase, Inc.에 저장돼요. 의견을 읽고 앱을 개선하는 목적으로만 사용해요. 저희 서버는 짧은 시간에 반복해서 보내는 것을 막으려고 IP 주소를 메모리에서만 잠시 쓰고, 의견과 함께 저장하지 않아요. 의견은 1년이 지나면 삭제해요. 메시지와 보낸 사람을 연결하는 정보가 없어서, 개별 메시지에 답장하거나 나중에 요청을 받아 찾아낼 수는 없어요. 이 이전을 원하지 않으면 의견을 보내지 않으면 되고, 앱은 모든 기능을 그대로 쓸 수 있어요. EEA·영국에서의 법적 근거: 앱을 개선하려는 저희의 정당한 이익.
