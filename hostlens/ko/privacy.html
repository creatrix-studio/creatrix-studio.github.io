HostLens 개인정보처리방침

시행일: 2026년 10월 26일 · 제공자: Creatrix(크리에이트릭스) · 문의: creatrix.studio26@gmail.com

요약

  • 계정, 광고, 추적이 없고 어떤 데이터도 판매하지 않아요.
  • 네트워크 정보는 휴대폰 밖으로 나가지 않아요. IP 주소, 기기 이름, 스캔 결과, DNS 결과, 기록은 모두 휴대폰 안에서만 처리하고 저장해요.
  • 앱을 개선하기 위해 익명 사용 이벤트(Google Analytics for Firebase)와 오류 보고(Sentry)를 수집해요. 둘 다 설정 → 개인정보에서 끌 수 있어요. 유럽경제지역(EEA), 영국, 스위스 사용자에게는 사용 분석을 켜지 않아요.

휴대폰에만 남는 데이터

HostLens는 휴대폰의 네트워크 설정(로컬 IP 주소, 서브넷, 공유기 주소, DNS 서버)을 읽고, 연결 상태와 응답 시간을 재기 위해 로컬 네트워크와 공개 테스트 호스트(예: apple.com, 1.1.1.1)에 네트워크 요청을 보내요. 네트워크에서 찾은 기기를 포함한 결과는 휴대폰의 앱 저장 공간에만 보관되고, 직접 지우거나 앱을 삭제하면 사라져요. 저희는 이 데이터를 받지 않아요.

사용 분석 (Google Analytics for Firebase)

사용 분석이 켜져 있으면 '점검 완료', '결제 화면 표시', '구매 완료' 같은 익명 제품 이용 이벤트를 보내요. Firebase는 앱 인스턴스 식별자, 기기 모델, OS 버전, 앱 버전, 언어, 접속 정보로 추정한 대략적인 국가도 처리해요. 이벤트에는 IP 주소, 호스트 이름, 기기 이름, UPnP·SNMP 정보, DNS 결과, 주소 범위, 스캔 데이터가 절대 포함되지 않아요. 광고 기능은 꺼 두었고 광고 식별자(iOS의 IDFA, Android의 광고 ID)를 사용하지 않아요. 보관 기간은 2개월이에요. 제공자: Google LLC(미국).

오류 보고 (Sentry)

오류 보고가 켜져 있으면 앱이 멈추거나 비정상 종료될 때 기술 정보(스택 트레이스, 기기 모델, OS와 앱 버전)를 보내요. 전송 전에 앱이 보고서에서 IP 주소, 호스트 이름, 기기 이름, UPnP·SNMP 정보, DNS 결과, 주소 범위, 스캔 데이터 같은 네트워크 정보와 자유 형식 문맥을 지우고, 서비스도 IP 주소를 저장하지 않도록 설정해 두었어요. 보관 기간은 최대 90일이에요. 제공자: Functional Software, Inc. d/b/a Sentry(미국).

속도 측정과 공유기 페이지

속도 측정은 Netflix가 운영하는 FAST.com을 앱 안 브라우저로 열어요. 측정은 FAST.com의 개인정보처리방침에 따라 이루어지고, HostLens는 결과를 받지 않아요. '공유기 설정 열기'는 로컬 네트워크에 있는 내 공유기의 웹 페이지를 열어요.

의견 보내기

설정에서 의견을 보내면 메시지, 선택한 유형, 앱·OS 버전, 앱 언어가 전송돼요. 계정, 이메일 주소, 기기 ID, 네트워크나 기기 정보는 전송되지 않고, 사용자를 구분하는 ID도 만들지 않아요. 데이터는 '보내기'를 누를 때 암호화된 연결로 전송되고, 저희 서버(Oracle Cloud Infrastructure에서 운영)에서 처리되어 미국의 Supabase, Inc.에 저장돼요. 의견을 읽고 앱을 개선하는 목적으로만 사용해요. 저희 서버는 짧은 시간에 반복해서 보내는 것을 막으려고 IP 주소를 메모리에서만 잠시 쓰고, 의견과 함께 저장하지 않아요. 의견은 1년이 지나면 삭제해요. 메시지와 보낸 사람을 연결하는 정보가 없어서, 개별 메시지에 답장하거나 나중에 요청을 받아 찾아낼 수는 없어요. 이 이전을 원하지 않으면 의견을 보내지 않으면 되고, 앱은 모든 기능을 그대로 쓸 수 있어요. EEA·영국에서의 법적 근거: 앱을 개선하려는 저희의 정당한 이익.

결제

결제는 Apple(App Store) 또는 Google(Google Play)이 처리해요. iOS에서는 유료 앱 하나에 모든 기능이 포함돼요. Android에서는 일회성 구매로 HostLens Pro를 잠금 해제해요. 저희는 결제 정보를 볼 수 없어요.

보관과 파기

휴대폰에 있는 데이터는 앱에서 지우거나 앱을 삭제할 때까지 보관돼요. 사용 이벤트와 오류 보고는 위 보관 기간이 끝나면 각 제공자가 자동으로 삭제해요. 의견은 1년이 지나면 저희 데이터베이스에서 삭제해요. 저희는 별도 사본을 보관하지 않아요.

아동

HostLens는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 알면서 수집하지 않아요.

선택과 권리
